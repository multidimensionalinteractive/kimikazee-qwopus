# Kimikazee Qwopus Assets

This directory contains branding and visual assets for the Qwopus project.

## Files

- `qwopus-branding.png` - Main promotional artwork featuring the purple octopus mascot

## Brand Colors

- **Primary Purple:** `#9b59b6`
- **Glowing Purple:** `#a55eea`  
- **Electric Blue:** `#00d4ff`
- **Status Green:** `#00ff88`
- **Dark Background:** `#0a0a14`

## Usage

All assets are optimized for:
- GitHub README (hero image)
- Landing page hero section
- Discord/Twitter promotional posts
- Documentation headers
