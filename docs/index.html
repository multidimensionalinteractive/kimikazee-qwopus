What Makes This Different

Every other fine-tune just swaps weights. Kimikazee redesigned the inference pipeline — a second model handles the grunt work so your 9B model spends 100% of its cycles on hard reasoning.

🧠

Scratch Pad LLM

A dedicated 1.7B model runs at 287 tok/s — sub-4ms per token. Handles classification, pre-processing, and verification while the main model sleeps.

🔀

Intelligent Task Routing

Every request gets classified before touching the main model. Trivial queries resolve in under 200ms. Complex prompts get pre-processed — reducing main model input by 15-40%.

🗜️

Conversation Compression

The helper compresses old turns into structured summaries — 50-70% context savings. Fit 3× more conversation history in the same 4K window.

✅

Hallucination Gate

After generation, the helper cross-checks output for factual errors, syntax issues, and contradictions. ~85% detection rate at a fraction of main model cost.

⚡

Full GPU Offload

Both models run 100% on GPU. Flash Attention + q8_0 KV cache quantization. 5.3GB total VRAM used — 7.7GB headroom for whatever else you're running.

🔌

Drop-in Integration

Three files. Zero changes to existing server code. from scratchpad import ScratchPadRouter — works with any OpenAI-compatible endpoint.

Quick Start

Three steps. Go from zero to dual-model inference in under 5 minutes.

1. Launch the Helper Server bash 
# Start a second llama-server for the scratch pad
ik_llama.cpp-server \
  -m /models/SmolLM2-1.7B-Q4_K_M.gguf \
  --host 0.0.0.0 --port 8081 \
  -c 4096 -ngl 99 \
  --flash-attn -ctk q8_0
2. Add to config.yaml yaml 
# Kimikazee config — scratch pad section
scratchpad:
  enabled: true
  helper_url: "http://localhost:8081"
  helper_model: "SmolLM2-1.7B"
  max_tokens_classify: 64
  helper_temperature: 0.1
  helper_timeout: 5.0
3. Run the proxy bash 
# Launch the dual-model routing proxy on port 8082
python proxy.py
# Clients connect to localhost:8082 — auto-routes to SmolLM2 or Qwopus

The Stack

llama.cpp + ik_llama.cpp

Two inference backends — standard llama.cpp for the speed demon (287 tok/s), ik_llama.cpp for the reasoning powerhouse with Flash Attention and KV cache quantization.

Qwopus — Qwen3.5-9B Fine-tune

Jackrong's custom fine-tune on the Qwen3.5 architecture. 9B parameters of reasoning muscle. Q3_K_M quantized to 4.2GB — fits in VRAM with room to spare.

SmolLM2 1.7B — The Reflexes

Sub-4ms inference at 287 tok/s. Classifies, compresses, and verifies at speeds the main model can't touch. Only 1GB VRAM — pays for itself in one session.

FastAPI + Python

Async-first. OpenAI-compatible API. Three files to integrate. No framework lock-in — works with any llama-server instance out of the box.
